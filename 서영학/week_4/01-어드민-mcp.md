# 1. AI Agent 지식 베이스를 어드민 mcp 로 전달 

## 배경
- 현재 사내 AI Agent를 슬랙봇 형태로 전사적으로 활용 중
- 이번에 어드민 재개발 및 프로세스 일원화 과정 진행 
- 사내 AI Agent에 앱 콘텐츠 정보들에 대한 데이터 전달 필요

# 계획 
- 기존 notion 문서 mcp로 1차 수집 가공 
- 전사적으로 프로세스, 가이드 문서 수집 
- mcp 서버로 오픈할 도메인 기능 정리 
- 권한 재설계

# 예상 효과 
- mcp(with 권한) 사내 데이터에 대해 안전한 정보 처리  
- 코드, 문서 검색에 대한 토큰 절약
