## 서영학

### 에러 분석 에이전트 & 어드민 AI 도입

- 로그 수집을 확대하려고 하며, 프론트엔드/백엔드 로그를 통합하여 에이전트로 에러 분석을 할 수 있게 구상 중
- 현재 어드민 개편 중이며, 에이전트와 AI를 어드민에 녹여내고 싶음
- **핵심 목표**: 도입하면 바로 인사이트를 얻을 수 있도록 하는 것
  - 현재는 원인을 찾으려면 로그 탭에 들어가고, 로그인하고, 인증해야 하는 과정이 필요
  - Slack 메시지에서 1차적으로 테스트할 수 있도록 하고 싶음
  - **개발자가 아니라 문제를 발견한 사람도 직접 해결할 수 있게 접근성을 높이는 것**이 가장 큰 목표

## 예린

### 장애 대응 프로세스 자동화

- 장애 대응 프로세스가 매번 사람이 수동으로 하는 것이 비효율적
- **문제점**:
  - 해당 환경의 로그나 모니터링을 통해 원인 파악하고 대응책을 세우는 데 시간이 너무 오래 걸림
  - 대응 시기를 놓치는 경우도 있었음
- **제안**:
  - 모니터링하면서 평소와 다른 이상 지표가 있으면 코드베이스까지 확인해서 대응하게 하는 것
  - **Datadog MCP**를 붙여보면 1차 대응 시간을 빠르게 줄일 수 있을 것 같다

## 홍영준

### 1. 코드 기반 Q&A 에이전트

- 당근의 커비봇처럼, 기획자/다른 개발자들에게 정책이나 구현 관련 문의가 많이 들어옴
- 업무 롤링이 많아서 이것저것 해야 하고, 잘 모르는 부분은 코드를 항상 살펴보고 찾아봐야 함
- 분석하는 데 시간이 꽤 걸리고 복잡함
- **코드를 기반으로 AI가 답변해줄 수 있도록** 만들고 싶음
- 고민: 이걸 어떻게 잘 깎을 수 있을까

### 2. QA 테스트 케이스 자동 생성

- 최근 큰 프로젝트가 들어왔는데, 한 화면이 복잡하고 케이스가 굉장히 많음
  - 예: 주문서는 하나지만 커머스냐 음식이냐, API에 따라 화면 케이스가 다양
- QA 돌렸을 때 예상하지 못한 API 응답이나 화면 케이스가 나옴
- **기획서를 가지고 어떤 플로우들이 나올 수 있는지 AI가 경우의 수를 전부 생성**해주면 좋겠음

## 조영제

### 기획서 품질 개선 에이전트

- FE 개발자들이 공감하는 문제: 기획자로부터 받는 기획서에 비어있는 부분이 많음
- **현재 프로세스의 문제점**:
  - 기획자와 디자이너끼리 소통해서 가안을 만듦
  - 기획자가 디자이너에게 줄 때 모든 케이스를 생각하지 않고 넘김
  - 프론트 개발자에게 넘어올 때 생각하지 못한 케이스나 뭉뚱그려진 부분이 존재
  - 나중에 피드백할 때 채워달라고 해야 할 게 많음
- **원하는 것**:
  - 개발자 입장에서 필요한 것들 (에러 처리, 로딩 처리, 페이지 이동 등) 세세한 기획을 마크다운으로 뽑아서 AI에 넣으면 코드가 바로 나오는 것
  - 흩어져 있는 기획들을 모아서 플랜 모드로 새로운 기획서를 만들어 진행
  - **기획자분들이 AI와 소통하면서 개발자들이 바로 쓸 수 있는 마크다운을 만들어주는 에이전트**를 만들고 싶음
- **제약**: 보안팀 이슈가 있어서 당장 쓰기는 어렵지만, 올해 반기까지 기획자분들에게 피드백 받아보고 싶음

## 강주희

### QA 버그 리포트 생성 & AI 파이프라인 자동 진단

- 셀카 기반으로 사용자 갤러리 링크를 제공하는 서비스를 개발 중 (거의 완성, 내부 테스트 진행 중)
- **QA 버그 리포트 자동 생성**:
  - 1인 개발자라 QA 단계에서 넘어온 결함들을 한번에 취합해서 원인 분석하고 수정하는 데 시간이 너무 오래 걸림
  - 이를 자동화하는 에이전트가 있으면 좋겠음
- **AI 파이프라인 자동 진단 에이전트**:
  - 셀카를 업로드했는데 갤러리에 본인 사진이 없는 경우
  - 유사도만 높아서 다른 사진인데 나오는 케이스 (미스매치, 오매칭)
  - 이런 케이스들을 AI가 자동으로 분석해서 리포트해주는 에이전트를 개발하고 싶음
  - 사진 데이터와 실제 AI 추론 파이프라인을 태워서 파라미터 튜닝값 분석하면서 문제점 파악

## 송재룡

### 1. 아틀라시안 장애 대응 자동화

- Jira/Confluence를 관리하고 있는데, 로그 중앙화가 안 되어 노드 하나하나 들어가서 로그를 봐야 함
- 현재 로그 중앙화 진행 중이나, 아틀라시안 제품이라 에러를 봐도 할 수 있는 게 제한적
- 아틀라시안 공개 문서를 보고 조치해야 하는데 상당히 번거로움
- **고질적인 문제**: 장애가 터지면 담당자들끼리 차일피일 미루는 상황
- **원하는 것**: 특정 에러 로그가 쌓였을 때 아틀라시안 문서를 자동으로 검색해서 1차 대응책을 Teams로 바로 전달

### 2. 권한/세팅 자동화

- 권한이나 세팅을 사람이 수동으로 처리 중
- 회사 계약 확인, 계약한 맨먼스 초과 여부 체크 등을 수동으로 하고 있음
- **하루 약 50건** 들어오므로 자동화하면 좋겠음
- 계약 확인해서 권한 부여하는 프로세스 자동화 가능할 것으로 판단

## 우창완

### 1. 데일리 스크럼 자동화

- 어제 뭐 했고 오늘 뭐 하는지 공유하는 자리가 있는데, 이런 것을 다 채팅에 수동으로 공유하고 있음
- AI로 자동화하면 좋겠음

### 2. Slack PR 자동 리뷰

- 회사 노트북이 아니면 GitHub에 접속할 수 없는 환경
- 노트북을 항상 보고 있을 수 없는데, PR 리뷰가 되어야 머지가 가능
- 팀의 베스트 프랙티스를 기반으로 자동 리뷰해주는 에이전트를 만들고 싶음

### 3. 코드 변경 의도 파악 에이전트

- 요즘은 코드보다 변경하는 의도가 더 중요하다고 생각
- 코드 전체를 보기보다 **의도를 파악해주는** 에이전트를 만들고 싶음

### 4. 시멘틱 코드 검색

- GitHub 레포가 굉장히 많은데 히스토리도 잘 안 남고, GitHub 코드 서치도 정확하지 않음
- 정규식은 Enterprise 적용도 안 됨
- 최근 사내에 코드 서치 오픈소스를 도입했는데, 웹서비스로 브라우저에서 사용 가능하나 CLI로 하고 싶음
- 다른 레포에 비슷한 로직을 참고할 일이 많은데 텍스트 기반 검색으로는 원하는 결과를 찾기 어려움
- **시멘틱 임베딩 모델을 사용해서 코드를 임베딩**하면 해결될 것 같음
