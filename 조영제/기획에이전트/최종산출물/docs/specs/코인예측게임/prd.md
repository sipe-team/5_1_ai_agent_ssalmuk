## 1. 개요 (Overview)

업비트 사용자가 **하루에 한 번 BTC와 ETH의 24시간 후 가격이 ↑인지 ↓인지** 예측하는 게임 기능. 적중률이 누적되어 **5단계 티어**(브론즈/실버/골드/플래티넘/다이아몬드)가 부여되고, 예측 화면에서는 결정에 도움이 되는 **8개 인사이트 채널**을 카드 그리드로 제공한다.

베팅이 아닌 **순수 적중률 경쟁**이며, 게임 자체의 재미와 8채널 인사이트 노출을 통해 **체류시간 증가 → 매수/매도 전환**으로 연결한다.

### 한 줄 정의

> "오늘의 BTC/ETH가 오를지 내릴지, 8가지 시그널을 보고 찍어보세요. 적중률로 티어가 올라갑니다."

---

## 2. 문제 정의 (Problem Statement)

### 현재 상황

- 업비트 사용자는 매수/매도 결정을 위해 **여러 채널을 직접 돌아다닌다**: 차트 → X → 트레이딩뷰 → 블로그 → 디스코드 → 글래스노드/뒨 → 코인사이트.
- 신규/중급 사용자는 **각 채널을 어떻게 해석할지 모른다**. 데이터는 많지만 의사결정 전환이 어렵다.
- 거래소 앱 안에서 **재미 요소가 약하다**. 가격 알림 외에는 매일 들어올 이유가 부족하다.

### 가설

> 사용자가 매일 한 번 가격을 찍는 **가벼운 의사결정 행동**을 반복하면, 인사이트 카드 노출 → 학습 → 실제 거래로 자연스럽게 이어진다.

### 데이터·근거

- 업비트 사용자는 가격 변동 시 앱을 **하루 평균 6~10회 켠다** (가설, 검증 필요).
- 폴리마켓·카지노식 예측 게임이 글로벌 상승세 (확률 시장 트렌드).
- 업비트 데이터랩 / 커뮤니티 등 **자사 자산이 노출 부족**한 상태로 묻혀 있다.

> **검증 필요**: 출시 전 사용자 인터뷰 5명 + CS 요청 키워드 분석으로 위 가설 보강.

#### FR-001 (P0) — 24시간 가격 예측 게임

**설명**: 사용자가 매일 BTC와 ETH의 24시간 후 가격이 예측 시점 대비 ↑인지 ↓인지 한 번씩 선택한다.

**시간 정책 (단일 기준 — KST 서버시간)**:
- **마감 시각** = `예측 등록 시각 + 24h` (롤링, 사용자별 개별 마감, 코인별 독립).
- **마감가** = 마감 시각 ±15초 윈도우 내 서버 다중 소스 평균 (R-06).
- **무효 처리 동가 비교**: 예측가 vs 마감가 모두 **원 단위 반올림** 후 동일이면 무효 (소수점 변동 무시).
- **다중 소스 5%+ 괴리 시**: 무효 처리 (재계산 X), 사용자에게 "시세 데이터 검증 실패" 인앱 카드 노출.
- **시간대**: 모든 표기·푸시·로그는 KST 24시간제 (예: "마감 04-30 08:31 KST").

**인수 조건 (Acceptance Criteria)**:
- Given 로그인한 19세 이상 사용자가 예측 화면에 진입했을 때
- When BTC 카드의 ↑ 또는 ↓ 버튼을 탭하면
- Then 즉시 예측이 잠기고 (취소 불가), 예측 시점의 가격(스냅샷)·24h 후 마감 시각(KST)이 함께 저장된다.
- And 같은 코인을 24시간 이내에 다시 예측할 수 없다 (BTC와 ETH는 독립).
- And BTC와 ETH는 동시 등록 가능하나 각각 별도 1일 1회 카운터로 관리된다.
- And 24시간 후 마감가가 예측 시점 가격과 원 단위 반올림 동일하면 무효 처리(적중·미적중 어느 쪽도 카운트 안 함)된다.
- And 등록 진행 중 사용자가 화면을 이탈하면 서버에 도달한 등록은 유효(잠금), 도달 전 실패면 롤백 (idempotency key로 중복 차단).

**우선순위 근거 (RICE)**: Reach=업비트 DAU 전체, Impact=High(핵심 행동), Confidence=High, Effort=Med → **최고**

#### FR-002 (P0) — 적중률 누적 + 5단계 티어

**설명**: 누적 예측 횟수와 적중률에 따라 5단계 티어(브론즈→실버→골드→플래티넘→다이아몬드)가 부여된다.

**인수 조건**:
- Given 사용자의 누적 예측 결과가 결산되었을 때
- When 티어 기준 (예: 골드 = 누적 예측 ≥30 AND 적중률 ≥55%)을 충족하면
- Then 즉시 티어가 변경되고, 변경 시점에 인앱 배지 + 푸시(옵션)가 표시된다.
- And 티어가 떨어지는 경우(적중률 하락)도 동일하게 변경된다.
- And 티어 산정 윈도우는 **최근 90일** (영구 누적이 아니라 시즌형 슬라이딩 윈도우).

**티어 임계값 (운영 기준, 출시 후 데이터로 조정)**:
| 티어 | 누적 예측 ≥ | 적중률 ≥ |
|------|------------|---------|
| 브론즈 | 0 | — |
| 실버 | 10 | 50% |
| 골드 | 30 | 55% |
| 플래티넘 | 60 | 60% |
| 다이아몬드 | 100 | 65% |

**우선순위 근거**: 게임 자체의 동기부여 핵심 (티어 없으면 1회성 행동에 그침).

#### FR-003 (P0) — 8채널 인사이트 카드 그리드

**설명**: 예측 화면 하단에 8개 채널의 시그널을 카드 그리드로 노출한다 (Step 3에서 B안 선택). 각 카드는 **방향(↑/↓) + 강도(%)**로 요약하고, 탭 시 상세 시트가 열린다.

**인수 조건**:
- Given 예측 화면이 BTC 또는 ETH 컨텍스트로 열렸을 때
- When 카드 그리드 영역이 렌더링되면
- Then 8장의 카드가 4×2 (모바일) 또는 4×2 (데스크톱) 그리드로 표시되고, 각 카드 우상단에 **방향 + 강도 (예: "↑ 65%")**가 표시된다.
- And 카드 탭 시 풀스크린 시트가 열리고, 채널별 상세 정보 (코멘트 / 차트 / 인용 / 헤드라인 등)가 표시된다.
- And 카드 데이터가 5분 이상 stale이면 카드 우하단에 "5분 전" 같은 마지막 갱신 시각을 표시한다.
- And 데이터 fetch 실패 시 카드 자리에 "잠시 후 다시 시도해주세요" 플레이스홀더가 표시되고, **다른 카드는 정상 노출된다 (한 카드 실패가 전체를 막지 않음)**.

**우선순위 근거**: 본 기능의 차별점이자 자사 자산 노출 통로.

#### FR-004 (P0) — [채널] 업비트 데이터랩 카드

**설명**: 자사 데이터랩 지표를 카드 + 상세 시트로 노출.

**카드 표시**: 
- 김치 프리미엄 (예: "↑ 2.3%")
- 또는 24h 거래량 변화율 (예: "↓ 12%")
- 카드 1장에 시그널 1종, 6시간 단위로 로테이션

**상세 시트 표시**: 김치 프리미엄, 24h 거래량, 52주 고저점, 이동평균선(20일/60일) — 4개 차트.

**인수 조건**:
- Given 사용자가 데이터랩 카드를 탭했을 때
- When 상세 시트가 열리면
- Then 4개 지표가 차트와 함께 표시되고, 각 지표는 BTC/ETH 컨텍스트에 맞춰 자동 갱신된다.

#### FR-005 (P0) — [채널] 자체 커뮤니티 카드

**설명**: 예측 화면 내장 미니 커뮤니티. 오늘의 투표 결과 + 인기 코멘트.

**카드 표시**: 오늘 BTC/ETH 커뮤니티 투표 결과 (예: "↑ 62% (1,243명)").

**상세 시트 표시**: 
- 투표 막대그래프 (↑ % vs ↓ %)
- 인기 코멘트 Top 5 (좋아요·댓글 순)
- "코멘트 작성" 버튼 → 코멘트 입력
- 댓글 트리 (1단계 답글까지)

**인수 조건**:
- Given 사용자가 BTC 카드를 탭하고
- When "코멘트 작성"으로 글을 게시하면
- Then 즉시 노출되고, 신고 누적 3건 이상 시 자동 가림 처리된다.
- And 코멘트는 닉네임 + 티어 배지로만 표시된다 (실명 노출 금지).

#### FR-006 (P0) — [채널] 예측 고수 리더보드 카드

**설명**: 플래티넘+다이아몬드 사용자(상위 5%)의 **오늘 픽** 분포.

**카드 표시**: "고수 픽 ↑ 70%"

**상세 시트 표시**:
- 상위 50명 (다이아몬드 + 플래티넘) 중 오늘 BTC/ETH 예측 분포
- 각 사용자는 닉네임 + 티어 + 적중률만 (실명/지갑/포지션 노출 금지)
- 상위 10명 닉네임만 카드 형태로 노출 (해당 사용자의 90일 적중률 첨부)

**인수 조건**:
- Given 다이아몬드/플래티넘 사용자 50명 중 30명 이상이 오늘 예측을 마쳤을 때
- When 카드를 렌더링하면
- Then "고수 픽 ↑ N%" (N = 30명 중 ↑ 비율) 으로 표시된다.
- And 30명 미만이면 "데이터 부족 (현재 N명)"으로 표시된다.

#### FR-007 (P0) — [채널] 관련 기사 카드

**설명**: 최근 24시간 BTC/ETH 관련 기사 헤드라인.

**카드 표시**: 최신 기사 1건의 헤드라인 (예: "↑ 시그널: BlackRock ETF 신규 유입 …")

**상세 시트 표시**:
- 헤드라인 5건 (시간 역순)
- 각 기사: 제목 / 출처 / 발행 시각 / 헤드라인 톤 (긍정/중립/부정 자동 분류)
- 탭 시 외부 브라우저로 원문 이동

**인수 조건**:
- Given 24h 이내 BTC/ETH 키워드 기사가 5건 이상 수집되었을 때
- When 카드를 탭하면 5건이 표시된다.
- And 5건 미만이면 가용한 만큼만, 0건이면 "최근 기사 없음" 플레이스홀더.

#### FR-008 (P0) — [채널] X / 텔레그램 센티먼트 + 인플루언서 카드

**설명**: X(트위터)와 텔레그램 채널의 BTC/ETH 언급 어조 + 등록된 인플루언서 계정 멘션.

**카드 표시**: "센티먼트 ↑ 58% (1.2k 멘션)"

**상세 시트 표시**:
- 24h 멘션 어조 분포 (긍정 / 중립 / 부정)
- 운영이 큐레이션한 인플루언서 30명의 최근 멘션 5건 (인용 카드)
- 키워드 클라우드 (Top 10)

**인수 조건**:
- Given 24h 이내 BTC/ETH 멘션이 100건 이상 수집되었을 때
- When 카드를 렌더링하면
- Then 어조 분포가 표시된다.
- And 인플루언서 멘션은 운영이 검토한 30명에 한정된다 (자동 수집 X).

> **리스크**: X API 비용 + 데이터 라이센스. 출시 전 법무 검토 필수. 수집 실패 시 카드는 "데이터 일시 중단" 표시 후 다른 카드는 정상 노출.

#### FR-009 (P0) — [채널] 폴리마켓 카드

**설명**: 폴리마켓의 동일 코인 24h 가격 시장 확률.

**카드 표시**: "폴리마켓 ↑ 67%"

**상세 시트 표시**:
- BTC/ETH 24h 시장 확률 차트 (12h 추이)
- 시장 거래량 (USD)
- 외부 링크 (폴리마켓 시장 페이지)
- 한국어 안내 ("미국 예측시장 데이터, 한국 거래/베팅과 무관")

**인수 조건**:
- Given 폴리마켓 BTC/ETH 24h 시장이 활성 상태일 때
- When 카드를 렌더링하면 확률 + 거래량이 표시된다.
- And 한국 사용자에게 폴리마켓 베팅 권유나 참여 유도 텍스트는 절대 표시되지 않는다.

> **리스크**: 한국 규제 환경에서 외부 예측시장 데이터 단순 노출의 적법성 — 법무 검토 필수. 시장 비활성/API 실패 시 카드 비활성.

#### FR-010 (P0) — 결과 알림

**설명**: 예측 24시간 후 마감 시점에 결과를 알림.

**인수 조건**:
- Given 사용자가 24h 전 BTC를 ↑로 예측했고 마감 시각이 도래했을 때
- When 결과 결산이 완료되면
- Then 푸시 알림(앱 권한 시) + 인앱 결과 시트가 표시된다.
- And 푸시 거부 사용자에게는 다음 앱 진입 시 인앱 결과 카드만 표시된다.

#### FR-011 (P0) — 결과 화면 → 거래 진입 CTA

**설명**: 결과 화면에서 적중 시 "BTC 매수하러 가기" / 미적중 시 "다른 의견 보기 → 매수/매도" CTA.

**인수 조건**:
- Given 사용자가 BTC ↑ 예측에 적중했을 때
- When 결과 시트가 열리면
- Then "지금 BTC 매수하러 가기" CTA가 표시되고, 탭 시 업비트 거래 화면(BTC/KRW)으로 진입한다.
- And 미적중 시 "내가 놓친 시그널 보기" CTA가 표시되고, 탭 시 어떤 채널이 정답을 맞췄는지 비교 화면이 열린다.

## 7. 사용자 시나리오 (User Scenarios)

### 시나리오 1 (Happy Path) — 출근길 카페에서 첫 예측 [페르소나: 민수]

> 매일 출근길 카페에서 5분 안에 시장 감을 잡고 점심에 거래하는 흐름.

**상황**: 평일 오전 8:30. 민수가 카페에 앉아 업비트 앱을 켠다.

1. 메인 화면 상단 배너 "오늘의 예측"을 탭한다. → **예측 화면 진입**
2. BTC 차트 + 현재가가 보인다. 차트 아래 8장 카드 그리드:
   - 데이터랩 카드: "김프 ↑ 2.3%"
   - 커뮤니티 카드: "↑ 62% (1,243명)"
   - 고수 픽 카드: "↑ 70% (다이아 30명)"
   - 기사 카드: "BlackRock ETF 신규 유입…"
   - X 센티먼트: "↑ 58% (1.2k 멘션)"
   - 폴리마켓: "↑ 67%"
3. 카드 4개가 ↑로 합의 → 민수가 BTC ↑ 버튼을 탭한다.
4. 확인 다이얼로그: "BTC ↑ 예측을 등록합니다. 마감 시각: 내일 08:31. 취소 불가." → 확인.
5. 즉시 잠금 상태로 변경, 카드 그리드 위에 "예측 등록 완료" 토스트.
6. 같은 흐름으로 ETH도 예측 (1일 1회씩 코인별 독립).
7. 점심 12:30, 민수가 다시 앱을 켠다 → 예측 화면은 잠금 표시 + 8채널 카드는 여전히 갱신 중. 민수가 데이터랩 카드 탭 → 거래량 차트 보고 매수 결심.
8. 매수 화면으로 이동, BTC 매수 체결.

**성공 조건**: 진입 → 예측 → 인사이트 학습 → 실제 거래 30분 내 완료.

### 시나리오 2 (Happy Path) — 적중 후 매도 [페르소나: 민수, 24h 후]

1. 다음날 8:31, 마감 푸시 도착: "🎯 적중! BTC ↑ 1.8% 마감"
2. 푸시 탭 → 결과 시트 진입.
3. 결과 시트:
   - 큰 ✓ 아이콘 + "적중!"
   - 누적 적중률: 60% → 62% (▲2%p)
   - "다음 티어까지 7회 남음" 진행 바
   - **CTA: "지금 BTC 매도하러 가기"** (매수했었던 정보 기반)
4. 민수가 CTA 탭 → 업비트 BTC/KRW 매도 화면 → 차익실현.

**성공 조건**: 결과 알림 → 거래 진입까지 5분 내.

### 시나리오 3 (Edge) — 미적중 후 학습 [페르소나: 지영, 베테랑]

1. 마감 시점에 BTC가 -0.5% → 지영의 ↑ 예측은 미적중.
2. 결과 시트:
   - "미적중 (-0.5%)" 
   - "내가 놓친 시그널 보기" CTA → 채널별 정답 분포 화면
3. 채널 정답 분포 화면:
   - 데이터랩 ↑ (틀림), 커뮤니티 ↑ (틀림), 고수 픽 ↓ (정답), X 센티먼트 ↑ (틀림), 폴리마켓 ↓ (정답), 기사 부정적 (정답 가까움), 온체인 CEX 유입 ↑ (정답)
   - 정답 가까운 채널 3개 강조 (다음 예측 시 가중치 학습)

**성공 조건**: 미적중 후 이탈하지 않고 채널 비교 화면에서 60초+ 체류.

### 시나리오 4 (Edge) — 신규 가입 사용자 첫 예측 [페르소나: 수진]

1. 가입 직후 메인 → "예측" 탭 첫 진입 → 온보딩 시트:
   - "BTC와 ETH의 24시간 후 가격이 오를지 내릴지 찍어보세요. 베팅 없음, 1일 1회 무료."
   - "8개 시그널 카드를 참고하세요."
   - "맞출수록 티어가 올라갑니다." (브론즈 → 다이아몬드 시각화)
2. 첫 예측 가이드: BTC 카드를 강조하고, ↑ 또는 ↓ 탭 유도.
3. 예측 후 "축하해요! 첫 예측 등록 완료. 24시간 후 결과를 알려드릴게요."

### 시나리오 5 (Anti) — 미성년자 차단

1. 가입 시 KYC를 통과하지 않은 사용자가 예측 진입 시도.
2. 차단 시트: "예측 게임은 19세 이상 실명 인증 사용자만 이용할 수 있어요." + 인증 CTA.

### 시나리오 6 (Edge) — 한 채널 데이터 fetch 실패

1. X API 일시 장애로 X 센티먼트 카드 데이터 수집 실패.
2. 그 카드만 "데이터 일시 중단" 플레이스홀더로 표시.
3. **다른 7개 카드는 정상 노출**, 사용자는 그대로 예측 가능.

### 8-8. 네비게이션 정책

- 예측 메인 → 카드 상세: **시트 push** (스택)
- 결과 시트 → 거래 화면: **replace** (결과 시트 닫고 거래 화면 풀)
- 미성년자 차단 시트: **modal**, 닫기 버튼 없음, 인증 완료 시에만 닫힘
- 메인 → 예측 메인: **push**, 뒤로 가기로 메인 복귀 가능
- 푸시 → 결과 시트: 앱 종료 상태에서 콜드 부팅 시 메인 → 결과 시트 자동 push (백 스택 = 메인 1장)

### 8-9. 접근성·반응형 가이드

- 카드 그리드는 모바일 (≤768px) 4×2, 데스크톱 4×2 고정 (가로 더 늘어나지 않음).
- 컬러만으로 ↑/↓ 구분하지 않음 — 화살표 아이콘 + 텍스트 함께 노출 (적록 색맹 고려).
- 카드 탭 영역 ≥ 44×44 (Apple HIG 권장).
- VoiceOver/TalkBack: 카드 라벨 = "데이터랩, 김치 프리미엄 2.3% 상승, 2분 전 갱신, 자세히 보기".

## 9. 비기능 요구사항 (NFR)

### 9-1. 성능

| 항목 | 목표 |
|------|------|
| S-01 진입 → 카드 그리드 first paint | ≤ 1.5초 (P95, KT 4G) |
| 카드 데이터 fetch (캐시 hit) | ≤ 200ms |
| 카드 데이터 fetch (캐시 miss) | ≤ 1.5초, 그 이상 시 스켈레톤 → 부분 노출 |
| 예측 등록 (↑/↓ 탭 → 토스트) | ≤ 800ms |
| 결과 결산 지연 | 마감 시각 +5분 이내 푸시 100% (가용성) |
| 동시 예측자 처리 | 30,000 RPS 대응 (마감 직전 스파이크 가정) |

### 9-2. 가용성

| 항목 | 목표 |
|------|------|
| 예측 등록 / 결과 결산 | 99.9% (월 ~43분 다운) |
| 카드 인사이트 | 99.0% (각 채널 독립, 한 채널 다운이 다른 채널을 막지 않음) |
| 푸시 알림 | 99.5%, 발송 실패 시 인앱 카드로 대체 |

### 9-3. 모니터링·운영

- 8채널 카드별 응답 지연 / 실패율 대시보드 (그라파나).
- 일일 예측 등록 수 / 코인별 분포 / 시간대 분포.
- 마감 직전 30분 스파이크 모니터.
- 티어 변동 이벤트 로그 (승급/강등 횟수).

### 9-4. i18n / Localization

- 1차 한국어만. 영문 i18n은 P2.
- 외부 데이터 (X 인플루언서, 폴리마켓, 영문 기사)는 원문 노출 + 한글 요약 1줄 (자동 번역, 출시 전 품질 검증).

> Note: 보안 기준선 / 데이터 모델 / API 명세는 본 PRD 범위 외 (후속 스킬 / 보안 에이전트가 처리).
