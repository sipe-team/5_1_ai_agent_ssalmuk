디자인 결정 메모

  • 한국식 시세 컨벤션: 상승=빨강 / 하락=파랑 (업비트 실제 앱과 동일).
  • 가격·% 등 숫자는 JetBrains Mono(tabular-nums)로 정렬, 라벨은 Spoqa Han Sans Neo.
  • 다크 테마에서 그림자 대신 밝기 단계(L0~L3)로 카드 위계 표현.
  • 카드 내 "stale 표시"는 우하단 아주 작은 점+분 단위. 5분 초과 시 점이 노란색으로 변함.
  • P1 카드(공식·온체인)는 dashed border + opacity 55%로 1차 출시 시 잠금 표시.
  • 티어 칩은 그라데이션 금지(anti-slop). 단색 outline + dot 마커로 구분.
  • 접근성: ↑/↓ 화살표 + 색상 + 텍스트 % 동시 사용 (적록 색맹 대응). focus-visible 골드 outline.
  • 모바일 우선(375x760 디바이스 프레임). 데스크톱에서는 4프레임을 그리드로 나란히.
