# 네비게이션 정책 (Navigation Policy)

기획서의 "클릭 명세(8-1)"와 "페이지 전환 흐름(8-4)" 작성 시 적용되는 정책입니다.

---

## 네비게이션 타입 정의

| 타입 | 동작 | 뒤로 가기 | 사용 시점 |
|------|------|----------|----------|
| **push** | 스택에 새 화면 추가 | 이전 화면으로 복귀 | 일반적인 화면 이동 |
| **replace** | 현재 화면을 교체 | 이전-이전 화면으로 복귀 | 완료 화면, 리다이렉트 |
| **pop** | 스택에서 현재 제거 | - | 뒤로 가기, 닫기 |
| **modal** | 현재 위에 오버레이 | 모달 닫힘 | 선택, 상세 보기, 확인 |
| **bottomSheet** | 하단에서 올라옴 | 시트 닫힘 | 옵션 선택, 필터 |
| **toast** | 하단 일시 표시 | - | 성공/에러 피드백 |
| **deeplink** | URL로 직접 진입 | 앱 홈으로 | 외부 링크, 알림 탭 |

## 타입별 사용 기준

### push를 사용할 때
- 새로운 콘텐츠 화면으로 이동
- 사용자가 "뒤로 가기"로 돌아올 수 있어야 할 때
- 예: 목록 → 상세, 홈 → 카테고리

### replace를 사용할 때
- 되돌아가면 안 되는 화면 전환
- 예: 결제 처리 → 결제 완료 (완료 후 결제 화면으로 못 돌아감)
- 예: 로그인 → 메인 (로그인 화면으로 못 돌아감)
- 예: 온보딩 마지막 → 홈

### modal을 사용할 때
- 현재 맥락을 유지하면서 부가 작업
- 닫으면 원래 화면으로 복귀
- 예: 주소 선택, 날짜 선택, 확인 다이얼로그
- **규칙**: 모달 안에서 다른 모달 열지 않기 (최대 1depth)

### bottomSheet를 사용할 때
- 3개 이상의 옵션 중 선택
- 필터/정렬 변경
- 예: 정렬 기준 선택, 공유 방법 선택

## 뒤로 가기 정책

| 상황 | 동작 |
|------|------|
| 일반 화면 | 이전 화면으로 pop |
| 모달/시트 열려있을 때 | 모달/시트 닫기 (화면은 유지) |
| 폼 입력 중 | 미저장 경고 다이얼로그 표시 |
| 결제/인증 처리 중 | 뒤로 가기 차단 또는 중단 확인 |
| 스택 최하단 (홈) | 앱 종료 확인 또는 아무 동작 없음 |
| deeplink으로 진입 | 앱 홈으로 이동 |

## 확인 다이얼로그 정책

### 필요한 경우

| 상황 | 다이얼로그 필요 |
|------|---------------|
| 데이터 삭제 | **필수** — "삭제하면 복구할 수 없어요" |
| 미저장 이탈 | **필수** — "변경사항이 저장되지 않아요" |
| 결제/구매 | **불필요** — 결제 버튼이 이미 명시적 액션 |
| 로그아웃 | **필수** — "로그아웃하시겠어요?" |
| 화면 이동 | **불필요** — 일반적인 네비게이션에는 확인 불필요 |

### 다이얼로그 구성

```
제목: [동작]하시겠어요?
설명: [결과 설명]
CTA: [구체적 동사]하기 / 취소
```

## 중복 탭 방지 (Debounce)

| 대상 | 방지 방법 |
|------|----------|
| API 호출 버튼 | 클릭 즉시 비활성화, API 응답 후 활성화 |
| 결제 버튼 | 클릭 즉시 비활성화 + 전체 화면 로딩 |
| 네비게이션 | 동일 화면 push 방지 (연속 탭 무시) |
| 좋아요/찜 | optimistic update + debounce 500ms |

## 딥링크 정책

| 항목 | 규칙 |
|------|------|
| URL 구조 | `/{리소스}/{ID}` (예: `/orders/12345`) |
| 인증 필요 시 | 로그인 → 딥링크 대상으로 리다이렉트 |
| 없는 리소스 | 404 에러 화면 → "홈으로 가기" CTA |
| 공유 URL | 웹/앱 동일 URL, 앱 설치 시 앱으로 열기 |

## 전환 애니메이션 기준 (Transition Animation)

| 네비게이션 타입 | 애니메이션 | Duration | Easing |
|--------------|----------|----------|--------|
| push | slide-left (우→좌) | 250ms | ease-out |
| pop | slide-right (좌→우) | 200ms | ease-in |
| modal | fade + slide-up | 200ms | ease-out |
| bottomSheet | slide-up | 250ms | ease-out |
| toast | fade-in → 3초 유지 → fade-out | 200ms in / 150ms out | ease |

> 프로젝트 디자인 시스템에 별도 모션 가이드가 있으면 그것을 우선합니다.
> 이 기준은 디자인 가이드가 없을 때의 기본값입니다.

## 이 정책의 적용

기획서의 "클릭 명세(8-1)"에서 네비게이션 타입을 지정할 때, 
"페이지 전환 흐름(8-4)"을 그릴 때 이 정책을 기본으로 적용합니다.
프로젝트별 정책이 다르면 이 파일을 수정하세요.
