# 조건부 디자인 규칙

> Step 2에서 사용자의 답변을 기반으로 해당하는 규칙 세트를 활성화한다.
> 각 규칙은 **적용 조건**, **필수 패턴**, **추천 설정**, **금지 항목**으로 구성된다.

---

## 데이터 밀집형 (if_data_heavy)

**적용 조건**: 대시보드, 분석 도구, 관리자 패널, CRM, ERP

### 필수 패턴
- 고밀도 레이아웃 (여백 최소, 정보 최대)
- 데이터 테이블: `font-variant-numeric: tabular-nums`, 우측 정렬 숫자
- 상태 표시: 시맨틱 컬러 배지 (성공=초록, 경고=노랑, 에러=빨강)
- 사이드바 네비게이션: 240px 고정, 접기 가능
- 필터/검색: 상단 고정, 즉각 반응

### 추천 설정
- 폰트: 페어링 A (Pretendard) — 숫자 가독성 최적
- 색상: Cool Professional 팔레트 (B)
- `--leading-body: 1.5` (데이터 밀도 확보)
- `--text-body: 0.9375rem` (15px, 밀집 환경)

### 금지
- 그라데이션 배경 (데이터 판독 방해)
- 큰 히어로 섹션 (공간 낭비)
- 장식적 일러스트레이션

## 럭셔리 (if_luxury)

**적용 조건**: 프리미엄 브랜드, 패션, 고급 서비스, 호텔, 금융 프라이빗

### 필수 패턴
- 넓은 여백 (전체 화면의 40%+ 여백)
- 세리프 제목 (KoPub Batang 또는 Noto Serif KR)
- 절제된 색상 (2색 + 뉴트럴)
- 이미지 중심 (텍스트 최소)
- 미묘한 애니메이션 (느린 페이드, 200-400ms)

### 추천 설정
- 폰트: 페어링 C (프리미엄) 또는 E (전통+현대)
- 색상: Elegant Mono 팔레트 (E) — 무채색 + 골드 터치
- letter-spacing: -0.03em (제목), 0 (본문)
- line-height: 1.8-2.0 (여유로운 호흡)

### 금지
- 밝은 CTA 버튼 (차분한 톤 유지)
- 빽빽한 레이아웃
- 이모지, 배지, 알림 스타일 요소
- 애니메이션 과다

## 전환 집중형 (if_conversion_focused)

**적용 조건**: 랜딩 페이지, 가입 페이지, 결제 흐름, 온보딩

### 필수 패턴
- 명확한 CTA 계층: Primary 1개 + Secondary 1개 (동시에 2개 이상의 동등한 CTA 금지)
- F-패턴 또는 Z-패턴 시선 흐름
- 사회적 증거: 고객사 로고, 사용자 수, 실제 후기
- 기능→혜택 변환: "기능을 설명"이 아니라 "사용자가 얻는 것"을 서술
- 스크롤 내러티브: 문제 → 해결 → 증거 → 행동

### 추천 설정
- 폰트: 페어링 A (모던 클린) 또는 D (다이내믹)
- 색상: Primary CTA와 배경 대비 최대화
- 버튼: 48px+ 높이, 고대비

### 금지
- 여러 개의 동등한 CTA
- 산만한 네비게이션 (랜딩에서 내부 링크 최소)
- 정보 과밀 (한 섹션에 3개 이상 메시지)
- 가짜 긴급성 ("오늘만!")

## 콘텐츠 중심형 (if_content_focused)

**적용 조건**: 블로그, 매거진, 뉴스레터, 문서, 백서

### 필수 패턴
- 읽기 최적화: 35-40자/줄, line-height 1.75-1.8
- 긴 텍스트 가독성: 충분한 문단 간격, 부제목 활용
- 이미지와 텍스트의 조화: 풀블리드 이미지 + 좁은 텍스트 컬럼
- 목차/네비게이션: 긴 콘텐츠에서 섹션 점프

### 추천 설정
- 폰트: 페어링 B (따뜻한 에디토리얼)
- 색상: Warm Neutral (A) 또는 Elegant Mono (E)
- 본문 크기: 17-18px (읽기 편안)
- max-width: 680px (텍스트 컬럼)

### 금지
- 사이드바 광고/위젯으로 인한 가독성 방해
- 팝업, 모달 (읽기 흐름 차단)
- 작은 폰트 크기 (<16px)

## 헬스케어 (if_healthcare)

**적용 조건**: 의료, 건강, 약국, 의료기기

### 필수 패턴
- WCAG AAA 목표 (대비 7:1)
- 큰 텍스트: 본문 18px+, 제목 28px+
- 높은 대비 (색상만으로 정보 구분 금지)
- 오류 방지: 중요 행동에 확인 단계
- 단순한 네비게이션: 깊이 2단계 이하

### 추천 설정
- 폰트: 페어링 F (공공/정부) — 큰 기본 크기
- 색상: Nature (C) — 차분한 초록 기반
- 터치 타겟: 48px+ (더 큰 타겟)

### 금지
- 작은 텍스트 (16px 미만)
- 애니메이션 과다 (간질 유발 위험)
- 빨간색 과다 사용 (의료 환경에서 불안 유발)
- 복잡한 폼 (한 화면에 5개 이상 입력)

## 금융 (if_finance)

**적용 조건**: 은행, 투자, 보험, 핀테크, 결제

### 필수 패턴
- 신뢰감 전달: 안정적인 색상, 깔끔한 구조
- 실시간 데이터 표시: 숫자 가독성, tabular-nums
- 보안 느낌: 자물쇠 아이콘, HTTPS 표시, 인증 배지
- 정밀한 숫자 표현: 소수점, 통화 기호, 천 단위 구분

### 추천 설정
- 폰트: 페어링 C (프리미엄) — 금융 전문성
- 색상: Cool Professional (B) — 신뢰
- 숫자: `font-variant-numeric: tabular-nums`

### 금지
- 밝은 색상 과다 (불안정해 보임)
- 장식적 애니메이션
- 모호한 CTA (금융에서는 명확한 행동 표현: "송금하기", "계좌 개설")

## 이커머스 (if_ecommerce)

**적용 조건**: 쇼핑몰, 마켓플레이스, 구독 서비스

### 필수 패턴
- 상품 그리드: 2-4열, 일관된 이미지 비율
- 가격 위계: 할인가 강조, 원가 취소선
- 장바구니 접근성: 항상 보이는 장바구니 아이콘 + 수량
- 필터/정렬: 좌측 또는 상단 고정

### 추천 설정
- 폰트: 페어링 A (모던) 또는 D (다이내믹)
- 색상: 상품 이미지가 주인공이므로 UI는 뉴트럴 유지
- CTA: 높은 대비, "장바구니 담기" / "바로 구매" 명확

### 금지
- UI 색상이 상품 이미지와 충돌
- 가짜 긴급성 (허위 카운트다운, 허위 재고)
- 복잡한 결제 프로세스 (3단계 이내)

---

## 공공/정부 (if_government)

**적용 조건**: 정부 서비스, 공공기관, 비영리, 교육기관

### 필수 패턴
- 접근성 최우선: WCAG AA 필수, AAA 권장
- 단순한 네비게이션: 최대 2단계 깊이
- 명확한 언어: 한국어 표준어, 전문 용어 설명
- 인쇄 친화적: `@media print` 스타일 포함

### 추천 설정
- 폰트: 페어링 F (공공/정부) — Pretendard, 큰 크기
- 색상: 기관 CI 색상 기반, 뉴트럴 보조
- 본문: 17px+, line-height 1.8

### 금지
- 트렌디한 디자인 요소 (오래 유지해야 하므로)
- 동영상 자동 재생
- 복잡한 인터랙션 (JS 의존 최소화)
- 외부 CDN 의존 (보안 정책)
