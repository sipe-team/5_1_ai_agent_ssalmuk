# 디자인 품질 게이트

> Step 5에서 디자인 검증 시, `--audit`/`--critique` 시 참조한다.

---

## 1. 5차원 평가 프레임워크

각 차원 0-20점, 총 100점 만점.

### 차원 1: 철학 일관성 (Philosophy Consistency)

선택한 디자인 철학이 **모든 요소에** 일관되게 적용되었는가?

| 점수 | 기준 |
|------|------|
| 17-20 | 모든 요소가 하나의 철학에서 비롯된 것처럼 보임. 혼란 없음. |
| 13-16 | 대부분 일관. 1-2개 요소에서 방향 이탈. |
| 9-12 | 부분적 일관. 여러 철학이 충돌하는 영역 존재. |
| 5-8 | 불일관. 제목/본문/레이아웃이 각각 다른 방향. |
| 1-4 | 철학적 방향 없음. AI 기본 템플릿 느낌. |

**체크포인트**:
- [ ] 폰트 페어링이 선택한 철학에 맞는가?
- [ ] 색상 팔레트가 톤과 일치하는가?
- [ ] 레이아웃 밀도가 철학에 부합하는가? (미니멀→넓은 여백, 정보디자인→밀집)
- [ ] 컴포넌트 스타일이 통일적인가?

### 차원 2: 시각 위계 (Visual Hierarchy)

사용자의 시선이 **의도한 순서**대로 자연스럽게 흐르는가?

| 점수 | 기준 |
|------|------|
| 17-20 | 3초 내에 핵심 메시지를 포착. 시선 흐름이 매끄러움. |
| 13-16 | 핵심은 보이지만 보조 요소와의 구분이 아쉬움. |
| 9-12 | 여러 요소가 동등한 존재감으로 경쟁. |
| 5-8 | 핵심 메시지가 묻힘. 어디를 봐야 할지 모름. |
| 1-4 | 위계 없음. 모든 것이 같은 크기/무게. |

**체크포인트**:
- [ ] 각 섹션에 명확한 "주인공"이 있는가? (제목, 핵심 수치 등)
- [ ] 제목과 본문의 크기 비율이 1.5배 이상인가?
- [ ] CTA가 주변 요소와 확실히 구분되는가?
- [ ] 보조 텍스트(캡션, 라벨)가 시각적으로 약한가?

### 차원 3: 디테일 실행 (Detail Execution)

타이포그래피, 간격, 색상이 **정밀하게** 제어되었는가?

| 점수 | 기준 |
|------|------|
| 17-20 | 모든 간격이 그리드에 맞음. 색상 톤이 완벽히 통일. |
| 13-16 | 대부분 정밀. 미세한 불일치 1-2곳. |
| 9-12 | 간격이나 색상에 일관성이 부족한 곳이 보임. |
| 5-8 | 정렬 오류, 간격 불일치가 눈에 띔. |
| 1-4 | 정밀도 없음. 여기저기 들쑥날쑥. |

**체크포인트**:
- [ ] 모든 간격이 4px 그리드 위에 있는가?
- [ ] 같은 유형의 요소에 같은 토큰이 적용되었는가?
- [ ] 색상이 OKLCH 팔레트 내에 있는가? (하드코딩된 임의 색상 없는가?)
- [ ] font-weight가 2-3단계만 사용되었는가? (과다 weight 없는가?)
- [ ] border-radius가 일관적인가?

### 차원 4: 기능성 (Functionality)

디자인이 **목적에 복무**하고, 기술적으로 **정상 작동**하는가?

| 점수 | 기준 |
|------|------|
| 17-20 | 목적 완벽 달성. 반응형, 접근성 모두 충족. |
| 13-16 | 목적 달성. 일부 뷰포트/접근성에서 미세 문제. |
| 9-12 | 기본 목적은 달성하나 반응형/접근성 부족. |
| 5-8 | 데스크톱에서만 동작. 접근성 미충족. |
| 1-4 | 깨진 레이아웃. CTA 미작동. 접근성 전무. |

**체크포인트**:
- [ ] 반응형: 375px(모바일), 768px(태블릿), 1440px(데스크톱) 확인
- [ ] `<html lang="ko">` 설정 (layout.tsx)
- [ ] `break-keep` 또는 `word-break: keep-all` 적용
- [ ] 대비 4.5:1 이상 (본문 텍스트)
- [ ] 포커스 스타일 존재 (shadcn 기본 제공)
- [ ] 터치 타겟 44px 이상 (`min-h-11` 등)
- [ ] shadcn 컴포넌트 정상 임포트 확인

**HTML/CSS 전용 체크포인트**:
- [ ] 하드코딩 색상 없이 CSS Custom Properties(`var(--color-*)`) 사용
- [ ] BEM 네이밍 컨벤션 준수 (`.block__element--modifier`)
- [ ] 시맨틱 HTML 요소 사용 (`header`, `main`, `section`, `nav`, `footer`)
- [ ] 인라인 `style` 속성 미사용 (이메일 타입 제외)
- [ ] 외부 프레임워크 의존성 없음 (폰트 CDN만 허용)

### 차원 5: 차별화 (Differentiation)

AI 슬롭 패턴을 피하고, **고유한** 디자인이 되었는가?

| 점수 | 기준 |
|------|------|
| 17-20 | "AI가 만들었다"고 말하기 어려움. 브랜드 고유성 확보. |
| 13-16 | 대부분 고유. 1-2개 AI 클리셰 잔존. |
| 9-12 | 부분적으로 제네릭. 구조나 스타일에서 AI 느낌. |
| 5-8 | AI 기본 템플릿과 유사. Inter + 보라 + 3카드. |
| 1-4 | 100% AI 산출물 느낌. 어디서 많이 본 것. |

**체크포인트**:
- [ ] `references/anti-slop.md` 체크리스트 전항 통과
- [ ] CRITICAL 위반 0개
- [ ] WARNING 위반 2개 이하
- [ ] 구조가 "히어로+3카드+CTA" 기본이 아닌가?
- [ ] 콘텐츠가 실제 맥락을 반영하는가? (Lorem ipsum 아닌가?)

## 2. 통과 기준

| 총점 | 판정 | 행동 |
|------|------|------|
| **80-100** | 통과 | Step 6으로 진행. 디자인 전달. |
| **60-79** | 경고 | 부족 차원 명시. 사용자에게 보완 여부 확인. |
| **0-59** | 차단 | 부족 차원 나열. Step 4로 복귀하여 재작업. |

## 5. 고빈도 문제 Top 10

| # | 문제 | 증상 | 수정 |
|---|------|------|------|
| 1 | AI 기본 템플릿 | 히어로+3카드+CTA 구조 | 콘텐츠에 맞는 고유 구조 설계 |
| 2 | 시각 위계 부재 | 모든 요소가 같은 크기/무게 | 제목은 본문의 2-3배, CTA는 대비 최대 |
| 3 | 색상 과다 | 5개 이상 색상 산재 | OKLCH 팔레트 내로 제한 (Primary + Accent + Neutral) |
| 4 | 한국어 줄바꿈 | 글자 단위 줄바꿈 | `word-break: keep-all` |
| 5 | 폰트 위계 없음 | 제목/본문 같은 weight | 제목 600-700, 본문 400 |
| 6 | 간격 불일치 | 섹션마다 다른 여백 | 4px 그리드 + 토큰 시스템 |
| 7 | 가짜 콘텐츠 | 의미 없는 텍스트 반복 | 실제 맥락 반영 카피 |
| 8 | 접근성 미달 | 낮은 대비, 작은 터치 타겟 | WCAG AA + 44px 터치 타겟 |
| 9 | 반응형 미대응 | 모바일에서 깨짐 | CSS Grid + clamp() + 미디어쿼리 |
| 10 | 과도한 장식 | 불필요한 아이콘/그림자/애니메이션 | 기능적 요소만 남기기 |
